## מה הם סוכני AI?

![מה הם סוכני AI?](../../../translated_images/he/what-are-ai-agents.47a544a1d03481ab.webp)

אם זו הפעם הראשונה שלכם לחקור כיצד לבנות סוכן AI, ייתכן שיש לכם שאלות כיצד להגדיר בדיוק מהו סוכן AI.

דרך פשוטה להגדיר מהו סוכן AI היא על ידי הרכיבים שמרכיבים אותו:

**מודל שפה גדול** - ה-LLM יניע הן את היכולת לעבד שפה טבעית מהמשתמש כדי לפרש את המשימה שהוא רוצה להשלים והן לפרש את תיאורי הכלים הזמינים לביצוע המשימות.

**כלים** - אלו יהיו פונקציות, APIs, מאגרי נתונים ושירותים אחרים שה-LLM יכול לבחור להשתמש בהם כדי להשלים את המשימות שהתבקשו על ידי המשתמש.

**זיכרון** - כך אנו מאחסנים אינטראקציות קצרות וארוכות טווח בין סוכן ה-AI למשתמש. אחסון ושליפת מידע זה חשובים לשיפור ולשמירת העדפות המשתמש לאורך זמן.

## מקרה השימוש של סוכן ה-AI שלנו

![מה אנחנו בונים?](../../../translated_images/he/what-are-we-building.1ff3b9a752eb8570.webp)

בקורס זה, אנו הולכים לבנות אפליקציית סוכן AI שעוזרת למפתחים חדשים להתחבר לצוות הפיתוח של סוכני ה-AI שלנו!

לפני שנבצע כל עבודה פיתוחית, הצעד הראשון ליצירת אפליקציית סוכן AI מוצלחת הוא הגדרת תרחישים ברורים כיצד אנו מצפים שהמשתמשים שלנו יעבדו עם סוכני ה-AI שלנו.

עבור אפליקציה זו, נעבוד עם התרחישים הבאים:

**תרחיש 1**: עובד חדש מצטרף לארגון שלנו ורוצה לדעת מידע על הצוות אליו הצטרף וכיצד להתחבר איתם.

**תרחיש 2:** עובד חדש רוצה לדעת מה תהיה המשימה הטובה ביותר להתחיל לעבוד עליה.

**תרחיש 3:** עובד חדש רוצה לאסוף מקורות למידה ודוגמאות קוד שיעזרו לו להתחיל להשלים את המשימה.

## זיהוי הכלים והשירותים

עכשיו כשיש לנו את התרחישים, הצעד הבא הוא למפות אותם לכלים ולשירותים שסוכני ה-AI שלנו יצטרכו כדי להשלים את המשימות.

תהליך זה נופל תחת קטגוריית הנדסת הקשר (Context Engineering) כאשר נתמקד לוודא שלסוכני ה-AI שלנו יש את ההקשר הנכון בזמן הנכון כדי להשלים את המשימות.

נעשה זאת תרחיש אחר תרחיש ונבצע עיצוב סוכני טוב על ידי רישום משימת כל סוכן, הכלים והתוצאות הרצויות.

![עיצוב סוכן](../../../translated_images/he/agent-design.07edb7ae37f47803.webp)

### תרחיש 1 - סוכן חיפוש עובדים

**משימה** - לענות על שאלות לגבי עובדים בארגון כגון תאריך הצטרפות, הצוות הנוכחי, מיקום ותפקיד אחרון.

**כלים** - מאגר נתונים של רשימת עובדים נוכחיים ותרשים ארגון

**תוצאות** - יכול לשלוף מידע ממאגר הנתונים כדי לענות על שאלות כלליות על הארגון ושאלות ספציפיות על עובדים.

### תרחיש 2 - סוכן המלצות משימות

**משימה** - בהתבסס על ניסיונו של העובד החדש בתחום הפיתוח, להציע 1-3 בעיות שהעובד החדש יכול לעבוד עליהן.

**כלים** - שרת GitHub MCP כדי לקבל בעיות פתוחות ולבנות פרופיל מפתח

**תוצאות** - יכול לקרוא את 5 ההתחייבויות האחרונות בפרופיל GitHub ואת הבעיות הפתוחות בפרויקט GitHub ולהגיב עם המלצות בהתאם להתאמה

### תרחיש 3 - סוכן עוזר קוד

**משימה** - בהתבסס על הבעיות הפתוחות שהומלצו על ידי סוכן "המלצת המשימות", לחקור ולספק משאבים וליצור קטעי קוד כדי לעזור לעובד.

**כלים** - Microsoft Learn MCP למציאת משאבים ו-Code Interpreter ליצירת קטעי קוד מותאמים.

**תוצאות** - אם המשתמש מבקש עזרה נוספת, תהליך העבודה ישתמש בשרת Learn MCP לספק קישורים וקטעי קוד למשאבים ואז יעביר לסוכן Code Interpreter ליצירת קטעי קוד קטנים עם הסברים.
