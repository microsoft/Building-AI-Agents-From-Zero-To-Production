### Unachohitaji


Kila Somo lina sampuli yake ya msimbo ambayo unaweza kuendesha kwa ndani. Unaweza [kuteka hifadhi hii](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) kuunda nakala yako mwenyewe.

Kozi hii kwa sasa inatumia yafuatayo:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — mradi wenye mfano wa **mfululizo wa GPT-5** ulioanzishwa (kwa mfano `gpt-5.1`). Usitumie mifano iliyostaafu ya GPT-4o / GPT-4.1.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — ingia kwa kutumia `az login` kabla ya kuendesha sampuli yoyote
- **Python 3.12 au zaidi**

Tafadhali hakikisha una ufikiaji wa huduma hizi kabla ya kuanza.

> **💰 Gharama & usafishaji.** Masomo ya vitendo huunda rasilimali halisi za Azure — mradi wa Microsoft Foundry,
> uwekaji mfano, duka la vekta, na (katika Masomo 4–6) maajenti waliowezeshwa na masanduku ya zana.
> Hizi zinaweza kusababisha gharama wakati zipo. Unapomaliza somo — au kozi — futa
> rasilimali unazozihitaji. Njia rahisi ni kuweka kila kitu katika kikundi cha rasilimali kilichotengwa
> na kufuta kikundi kizima unapomaliza:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Pia unaweza kufuta maajenti binafsi, maduka ya vekta, na masanduku ya zana kutoka kwa lango la Foundry.

> **Kumbuka kuhusu mifano.** Kozi hii hutoa mifano yote kupitia **Microsoft Foundry**. Hai
> tumii *GitHub Models*, ambayo itastaafu tarehe **30 Julai, 2026** — Microsoft Foundry ni njia rasmi ya uhamisho.
> Kama una msimbo wa zamani unaoitumia GitHub Models, lekezwa kwa uwekaji mfano wa Foundry badala yake.
